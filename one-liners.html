Cheat sheet

FFmpeg quick one-liners

Drop-in commands for the most common FFmpeg tasks. Copy, tweak the input/output, run.

Hit Explain on any row to break the command down flag-by-flag.

TaskCommandDetails
Convert to MP4 (H.264 + AAC) ffmpeg -i input -c:v libx264 -crf 23 -c:a aac output.mp4
-i input
Input file path. FFmpeg detects the format from the file's contents, not from the extension.
-c:v libx264
Encode the video stream with libx264 (the H.264 encoder). H.264 is decoded everywhere — browsers, phones, TVs.
-crf 23
Constant Rate Factor: aim for a constant perceived quality and let the bitrate float. Lower = better quality, larger file. Range 0–51; 18 is visually lossless, 23 is x264's default.
-c:a aac
Re-encode the audio as AAC (the default audio codec for MP4).
output.mp4
Output file. The .mp4 extension chooses the container.
Trim a clip (fast, keyframe-aligned) ffmpeg -ss 00:00:30 -to 00:01:00 -i input -c copy clip.mp4
-ss 00:00:30
Seek to this start time. Placed before -i for fast input seeking — FFmpeg jumps straight to the prior keyframe.
-to 00:01:00
Stop at this absolute timestamp (not a duration relative to -ss).
-i input
Source file.
-c copy
Stream copy — no re-encoding, near-instantaneous.
clip.mp4
Output. Cut points snap to the nearest keyframe, so the clip may open with a frozen frame if your start time isn't on one.
Remove the audio track ffmpeg -i input -c copy -an silent.mp4
-i input
Source file.
-c copy
Copy streams as-is (no re-encode).
-an
Drop all audio streams from the output.
silent.mp4
Output, video-only.
Extract audio to MP3 ffmpeg -i input -vn -q:a 0 -map a audio.mp3
-i input
Source file.
-vn
Drop the video stream.
-q:a 0
Highest VBR quality for the chosen audio codec (0 = best, 9 = worst). For MP3 this maps to LAME's V0 preset (~245 kbps average).
-map a
Pick all audio streams from the input.
audio.mp3
Output. The .mp3 extension picks the LAME encoder.
Resize to 720p (keep aspect) ffmpeg -i input -vf scale=-2:720 -c:a copy out.mp4
-i input
Source file.
-vf scale=-2:720
Video filter: scale to 720 pixels tall; the width is computed from the aspect ratio. Using -2 instead of -1 rounds the computed width to a multiple of 2, which most encoders require.
-c:a copy
Don't re-encode audio.
out.mp4
Output.
Make a GIF ffmpeg -i input -vf "fps=15,scale=480:-1:flags=lanczos" out.gif
-i input
Source file.
fps=15
Drop framerate to 15 fps — GIFs get heavy fast at higher rates.
scale=480:-1
Resize to 480 wide; height computed from aspect ratio.
flags=lanczos
Use the Lanczos scaler — slower but visibly sharper than the default bilinear.
out.gif
Output. For substantially better GIF quality consider a two-pass palettegen / paletteuse workflow.
Normalize loudness (EBU R128) ffmpeg -i input -af loudnorm=I=-16:TP=-1.5:LRA=11 out.mp4
-i input
Source.
-af loudnorm=…
Audio filter that implements EBU R128 loudness normalization.
I=-16
Target integrated loudness, in LUFS. -16 is a common podcast / streaming target; YouTube and Spotify normalize to roughly -14.
TP=-1.5
True-peak ceiling, in dBTP. Prevents inter-sample clipping when re-encoded by a downstream codec.
LRA=11
Target loudness range, in LU. Higher = more dynamics preserved.
out.mp4
Output. For best accuracy run two passes — analysis pass, then a second pass with the measured values baked in.
Single frame at a timestamp ffmpeg -ss 00:01:00 -i input -frames:v 1 out.jpg
-ss 00:01:00
Seek to t = 60s (fast input seek).
-i input
Source file.
-frames:v 1
Output exactly one video frame.
out.jpg
Output. For higher-quality JPEGs add -q:v 2.
Contact-sheet thumbnails ffmpeg -i input -vf "fps=1/60,scale=320:-1,tile=4x4" sheet.jpg
-i input
Source file.
fps=1/60
Sample one frame every 60 seconds.
scale=320:-1
Resize each sampled frame to 320 wide; height follows the aspect ratio.
tile=4x4
Pack 16 sampled frames into a single 4×4 grid image. Bump it to 5x5 or 6x6 for longer videos.
sheet.jpg
The contact sheet.
Inspect a file (codecs, bitrate, duration) ffprobe -hide_banner input.mp4
ffprobe
Read-only inspector that ships alongside ffmpeg. Prints stream info (codec, resolution, bitrate, duration) without producing any output file.
-hide_banner
Skip the build / version / configuration block that ffprobe prints at startup.
input.mp4
File to inspect. Add -show_streams -show_format -of json for machine-readable output.
